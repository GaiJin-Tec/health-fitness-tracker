# Health & Fitness Tracker

Free, mobile-friendly progressive web app (PWA) for estimating calories burned from MET, body weight, and duration. No server or API required.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub, e.g. `health-fitness-tracker`.
2. Upload all files and the `icons` folder from this project to the repository root. If using the ZIP, unzip it first; do not upload the ZIP as the website.
3. Go to **Settings → Pages → Build and deployment**.
4. Set **Source** to **Deploy from a branch**, **Branch** to **main**, and folder to **/(root)**, then Save.
5. Once deployed, open `https://YOUR_USERNAME.github.io/health-fitness-tracker/`.
6. On iPhone Safari, tap **Share → Add to Home Screen**.

The app works offline after its initial successful load. Calculations are estimates, not medical measurements. Data is not saved.
